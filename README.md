# Солнечная ферма

Прототип изометрической фермы в стиле Township на **Phaser 4** + TypeScript + Vite.
Игра рассчитана на **вертикальный телефон**. Если повернуть телефон горизонтально, появится просьба вернуть его вертикально. На компьютере игра открывается в «телефонной» рамке по центру, чтобы её было удобно проверять.

## Играть

https://sergeimusailov.github.io/1masiuy4gjadfk/ — публикуется автоматически при каждом обновлении `main` (GitHub Pages).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (с телефона: npm run dev -- --host и открыть IP компьютера)
npm run build    # production-сборка в dist/
```

## Что есть в игре

- Остров с обрывами, волнами, пеной у берега, прудом, облаками и их тенями.
- Грядки: нажмите на пустую, выберите культуру (пшеница; морковь открывается на 2 уровне). Растение растёт в 3 стадии, спелое светится и искрится.
- Сбор урожая: листья и зёрна разлетаются, иконки по дуге летят в счётчик, начисляется опыт.
- Лес за мостиком: на поляне сами вырастают грибы — шампиньоны, лисички и редкие белые. Появляются в случайных местах (иногда у самых кустов), растут в 3 стадии; спелый гриб при сборе звенит, как монетка в играх Nintendo, и по дуге улетает в амбар.
- Амбар: нажмите, чтобы продать весь урожай и грибы, монеты полетят в счётчик.
- Кнопка «Грядка»: режим строительства с подсветкой свободных клеток. Новая грядка падает с пылью и тряской камеры.
- Новый уровень: баннер, лучи, конфетти.
- Живой мир: мельница крутится (нажмите — ускорится), куры бродят и клюют (нажмите — подпрыгнут), бабочки, дым из трубы, деревья качаются.
- Камера: перетаскивание с инерцией, масштаб щипком двумя пальцами или колесом мыши.
- Постобработка: bloom и виньетка на камере, Glow на спелых грядках и зданиях.
- Прогресс сохраняется в `localStorage`; растения растут, пока игра закрыта.
- Звуки синтезируются через WebAudio, аудиофайлов нет.

## Как устроен код

```
src/
  main.ts            запуск Phaser: WebGL, чёткость на Retina (канвас в физических пикселях)
  game/state.ts      модель: монеты, опыт, грядки, правила. Графики здесь нет
  game/world.ts      изометрическая математика (iso / unIso) и раскладка острова
  game/art.ts        процедурная графика: все текстуры рисуются Canvas 2D
  game/sfx.ts        синтез звуков
  game/viewport.ts   портретный режим, рамка на десктопе, safe area iPhone
  scenes/FarmScene.ts  мир: тайлы, сортировка по глубине, частицы, камера, ввод
  scenes/UIScene.ts    HUD поверх мира: счётчики, кнопки, летящие иконки
```

Основные приёмы:
- **Изометрия 2:1.** Тайл 256×128. Объекты сортируются по мировому Y (`setDepth(y)`), поэтому ближние перекрывают дальние.
- **Логика отдельно от отрисовки.** `GameState` шлёт события (`plot`, `coins`, `levelup`), сцены на них реагируют.
- **Две сцены.** Интерфейс не масштабируется вместе с камерой мира.
- **Анимации** сделаны на твинах с easing (`Back.Out`, `Bounce.Out`), эффекты — на эмиттерах частиц и фильтрах Phaser 4.
